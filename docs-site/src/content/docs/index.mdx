## 快速开始

```bash
# 1. 安装
npm install -g imtoagent

# 2. 交互式配置（支持 ↑↓ 键盘选择）
imtoagent setup

# 3. 启动网关（后台运行，终端立即返回）
imtoagent start
```

## 核心架构

```
IM 适配器 → IM Registry 工厂 → Bot 实例 → AgentRuntime → Agent Adapter → 统一 Proxy :18899 → 上游模型
```

| 层级 | 组件 | 说明 |
|------|------|------|
| IM 层 | Feishu / Telegram / WeCom / WeChat | WebSocket / 长轮询 / Webhook 回调 |
| 网关层 | Bot + AgentRuntime | 消息路由、会话管理、错误处理 |
| Agent 层 | Claude / Codex / OpenCode | spawn 子进程 / HTTP API |
| Proxy 层 | Anthropic Proxy :18899 | 统一代理，所有请求转上游 |
